Welcome to my personal *home on the internet* where I share things about myself: what I'm thinking about, what I'm working on, and what I'm learning.

Like life itself, this website is forever a *work in progress*.

## Technology

This website is generated using a static website generator built with [Swift](https://swift.org).

It uses a simple layout system built around `VStack`s and `HStack`s, inspired by [SwiftUI](https://developer.apple.com/xcode/swiftui/).

The source code is available on [GitHub](https://github.com/fluffybeing/fluffybeing.github.io).
